# Madera Noble - Carpintería Premium

Sitio web profesional de carpintería ficticia construido con Next.js, Tailwind CSS y Framer Motion.

## Características

- Diseño premium y elegante inspirado en madera
- Animaciones suaves y microinteracciones
- Catálogo de productos centralizado
- SEO optimizado (meta tags, Open Graph, sitemap, structured data)
- Accesible (WCAG 2.1 AA)
- Responsive
- Listo para Vercel

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Instalación

```bash
npm install
npm run dev
```

## Deploy en Vercel

1. Conecta tu repositorio GitHub a Vercel
2. El framework se detecta automáticamente (Next.js)
3. Deploy sin configuración extra

## Estructura de datos

Toda la información editable está en `app/data/`:
- `company.ts` - Marca, contacto, historia
- `products.ts` - Catálogo de muebles
- `testimonials.ts` - Testimonios
- `navigation.ts` - Links de navegación
- `seo.ts` - Meta tags y Open Graph

## Variables de entorno

Copia `.env.example` a `.env.local` y ajusta según necesites.
